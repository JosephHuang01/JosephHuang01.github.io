# Joseph Huang Portfolio

This repository contains a lightweight personal portfolio website hosted via GitHub Pages.

## Overview

The site is a static HTML, CSS, and JavaScript project designed to showcase:
- a personal landing page
- an about section
- project categories
- a contact section linked to LinkedIn
- multiple color themes for a more dynamic experience

## Files

- `index.html` — main page structure and content
- `styles.css` — styling, layout, and theme definitions
- `script.js` — theme switching behavior

## Local Preview

You can preview the site locally by running a simple HTTP server from the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## GitHub Pages

This repository is intended to be published as a GitHub Pages site. If the repository is connected to GitHub Pages, the live site will be available at:

```text
https://josephhuang01.github.io/
```

## Notes

- No backend is required for this project.
- The site is easy to customize by editing the content in `index.html` and the styling in `styles.css`.
- The project keeps the structure minimal and portable for GitHub hosting.
